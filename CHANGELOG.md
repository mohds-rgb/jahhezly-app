# Changelog

- Aligned the product with general retail Click & Collect for Syria.
- Added owner identity, proprietary licensing, and public repository metadata.
- Added owner-authorized Paris Market and cham-center merchant scenarios.

- Added mobile source-structure validation.
- Expanded backend tests and migration chain to `0004`.
- Added notification boundary documentation.
