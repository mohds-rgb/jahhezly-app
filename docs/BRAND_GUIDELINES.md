# Jahhezly Brand Guidelines

## Source asset

The supplied Jahhezly app icon is stored at:

- `assets/brand/jahhezly-icon-original.jpg` — owner-supplied source image
- `assets/brand/jahhezly-icon-square.png` — repository-friendly square crop derived from the owner-supplied image

The owner states that the icon was designed by him and is fully owned by him.

## Palette

The visual system is intentionally derived from the icon rather than invented independently. Representative sampled colors are:

| Token | Hex | Usage |
|---|---|---|
| `jhNavy` | `#1A2671` | Primary brand, headers, navigation |
| `jhOrange` | `#EA5521` | Primary action/accent |
| `jhMint` | `#69B2A5` | Positive/confirmed states |
| `jhSurface` | `#F4F6FA` | App surfaces/backgrounds |
| `jhInk` | `#172033` | Primary text |
| `jhMuted` | `#667085` | Secondary text |

## Direction

The design language is:

`utility · trust · speed · clarity · compact retail workflow`

The icon already carries a strong visual motif: orange movement/flow, a check mark, and a deep navy field. The UI therefore uses restrained shapes, strong hierarchy, and limited accents rather than decorative gradients or glossy effects.

## Typography

Recommended portfolio pairing:

- Latin: Inter
- Arabic: Noto Sans Arabic

Font files are not bundled into this repository. Platform-safe/system equivalents may be used at runtime.

## Layout

- 4pt base spacing rhythm
- 12–16px card/input radii
- Clear status chips for `Available`, `Stale`, `Pending`, `Ready`
- Strong action buttons for store operators
- Status is never communicated only by color

## Product surfaces

The customer surface emphasizes catalog speed and low cognitive load. The merchant surface emphasizes queue scanning, status transitions, and error prevention.
