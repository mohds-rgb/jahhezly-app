# Security Policy

Jahhezly is a portfolio repository, not a deployed service.

Implemented controls include server-side merchant authorization, tenant/store scoping, memory-hard password hashing, JWT expiry, typed request validation, idempotent order submission, optimistic concurrency and audit events.

Never commit passwords, JWT secrets, API tokens, signing keys, service-account files or real customer data.

Replace the placeholder security contact with an owner-approved address before public release.
